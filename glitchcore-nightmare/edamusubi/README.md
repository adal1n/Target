# えだむすび (Edamusubi) feat. 重音テト

> 가지에 묶는 매듭. 유대(絆)라는 밧줄이 사람을 조르고, 사회라는 나무에 매달리는 이야기.
> 클라이맥스에서 **가지가 부러진다** — 죽음조차 거절당하고 진흙 속에서 다시 숨을 쉬고, 풀린 밧줄은 다음 사람을 향한다.

- Key: D minor / BPM 201.36 / 4/4 / 약 3:05
- 반주: `../maretu-arrange` 마레츠풍 편곡 + 효과음
